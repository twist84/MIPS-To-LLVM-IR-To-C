01 / ARCHITECTURE

Two parts. One execution path.

The compiler translates original guest code. The runtime supplies the surrounding hardware and guest-visible services. Neither substitutes rewritten game logic.

COMPILEREE / R5900

Translate the guest

Discover executable functions and control flow, lift supported integer, MMI, COP1 and COP2/VU0 operations, verify IR and emit linked native code.

Static discovery
ELF symbols, direct calls and conservative JALR resolution
Native dispatch
Indexed guest-PC lookups and live translation-cache overlays
Backend
LLVM IR + llvmlite objects; general IR-to-C emission remains incomplete
Compiler validation ↗
RUNTIMEHLE-FIRST

Run the machine

Execute original guest code with an experimental BIOS-free runtime, native VU1 compilation, device services and a native renderer.

Graphics
Asynchronous VU1/GS workers and native WebGPU presentation
Audio
Guest-clock SPU2, optional 48 kHz stereo PCM through raudio
Devices
Guest IOP modules, SIF/RPC, CDVD, DMA, controllers and memory cards
Runtime architecture ↗
Design principle

Preserve guest-observable behavior. Investigate unsupported operations instead of fabricating interrupts, readiness or completion. The current compatibility clock is not calibrated R5900 cycle timing.

What these numbers do not prove

The warmed replay predates final PR #156, was device-free profiling and used input that was not strictly neutral. Matching GPU-authoritative captures are not independent raster validation. Sustained gameplay, other titles, calibrated timing, clean test termination and full hardware compatibility remain open. The earlier 7,901-module static-discovery validation is distinct from the expanded retail cache.

04 / GET STARTED

Build. Run. Investigate.

Install CMake, Ninja, a C++ toolchain and Python with llvmlite. The original console test suite requires no commercial game or BIOS.

BUILD & VALIDATE shell
# Clone and build
git clone https://github.com/twist84/MIPS-To-LLVM-IR-To-C.git
cd MIPS-To-LLVM-IR-To-C
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2

# Run regressions and original console tests
ctest --test-dir build --output-on-failure
python tools/run_ps2autotests.py

# Windows: graphical launcher
python tools/launch_ps2_gui.py

Run a retail game

On Windows, supply your own extracted disc under PS2_GAME/, including SYSTEM.CNF.
