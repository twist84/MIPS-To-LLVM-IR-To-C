02 / UNDER THE HOOD

Built for the hard parts.

The goal is original guest behavior, not a reimplementation of the game's logic. Unsupported behavior is investigated rather than silently skipped.

⌘COMPILER

Instruction-accurate ambitions.

R5900 integer and multimedia operations, COP1, selected COP2/VU0 behavior, branching, delay slots and register liveness are covered by focused regressions and original-console transcript tests. Native VU1 microprograms support validated AOT loading with fallback.

decode→lift→verify→link
▧GRAPHICS

Real GS output.

Committed GIF traffic feeds a native WebGPU rendering path with guest-configured framebuffers, field-driven presentation and asynchronous VU1/GS workers.

⌁HARDWARE

More than CPU code.

HLE-first devices, original guest IOP modules, SIF/RPC, DMA, controller input, memory cards and BIOS-free extracted-disc boot. SPU2 uses guest-clock mixing with optional 48 kHz stereo output through raudio.

◎OBSERVABILITY

Debug the machine, not just the symptom.

Translation provenance, live cache-miss recovery, indexed dispatch, replay logs, IR validation, device counters and profiling help isolate faults without inventing guest progress.

05 / GET INVOLVED

Explore the source.

Build the host tools, inspect the LLVM IR pipeline, launch your own extracted disc, or run the original console tests. Install CMake, Ninja, a C++ toolchain and Python with llvmlite.

›_Get the projectTERMINAL
# Clone the source
git clone https://github.com/twist84/MIPS-To-LLVM-IR-To-C.git
cd MIPS-To-LLVM-IR-To-C

# Configure and build host tools
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2

# Run the regression suite
ctest --test-dir build --output-on-failure

# Original console transcripts
python tools/run_ps2autotests.py

# Windows: graphical launcher
python tools/launch_ps2_gui.py
